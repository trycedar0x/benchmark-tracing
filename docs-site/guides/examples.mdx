Use a throwaway `EVERYBENCH_HOME`, unset current/legacy database URLs and run the callable fixture first. Tracing examples require a loopback `everybench serve` receiver; it defaults to metadata. Set `EVERYBENCH_INGEST_CONTENT` deliberately before capturing content. Shared/reverse-proxied servers require authentication and TLS.

Portable helpers remain self-contained in their skill folders: [SDK smoke](https://github.com/trycedar0x/benchmark-tracing/blob/main/skills/everybench-sdk/scripts/trace_smoke.py) and [read-only comparison gate](https://github.com/trycedar0x/benchmark-tracing/blob/main/skills/everybench/scripts/evaluate.py). The latter takes two existing run IDs and does not create jobs. Old model/Harbor/quote execution examples have been removed.
