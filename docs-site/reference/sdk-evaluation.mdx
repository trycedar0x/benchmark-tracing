## evaluate

```python
async evaluate(benchmark: 'Benchmark | str', agent: 'AgentTarget | AgentCallable', *, trace_source: 'TraceSource | None' = None, allow_paid: 'bool' = False, sample_ids: 'list[str] | None' = None, limit: 'int | None' = None, timeout: 'float' = 40, trace_timeout: 'float' = 10, grading_timeout: 'float' = 180, content_policy: 'str' = 'redacted', workspace_id: 'str | None' = None, target_config: 'dict[str, Any] | None' = None, judge_models: 'list[str] | None' = None, extractor_model: 'str | None' = None, data_path: 'str | Path | None' = None, tolerance: 'float' = 0.01) -> 'EvaluationReport'
```

Evaluate once per selected original case, with no implicit retries.

``allow_paid=True`` consents to target and evaluator invocations, not a billing cap.
Config is declared public identity, not secrets; fingerprints are not revision proofs.
Cancelling this coroutine persists a cancelled report then propagates cancellation.
Synchronous callable threads cannot be forcibly stopped by Python.
